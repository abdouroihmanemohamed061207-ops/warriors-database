
# Warriors Database 🏀

Projet personnel réalisé dans le cadre de mon
apprentissage en BTS SIO, option SLAM.

## Présentation

Warriors Database est un site web non officiel
consacré aux Golden State Warriors.

Il présente :
- Cinq joueurs emblématiques et leurs fiches détaillées
- Les sept titres NBA de la franchise
- Des photographies et des liens vers des vidéos
- Une base de données MySQL
- Une interface d'administration locale

## Technologies utilisées

- HTML / CSS
- PHP
- MySQL
- PDO
- WampServer / phpMyAdmin

## Installation en local

1. Installer WampServer.
2. Copier le dossier dans `C:\wamp64\www`.
3. Démarrer Apache et MySQL.
4. Importer `database.sql` dans phpMyAdmin.
5. Configurer les identifiants MySQL dans `config.php`.
6. Ouvrir `http://localhost/warriors-database/`.

## Objectif pédagogique

Découvrir le développement d'un site dynamique,
la connexion PHP/MySQL, les requêtes SQL
et l'affichage des données provenant d'une base.
